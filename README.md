# Slab Row

A virtual card show. Walk a 3D floor with friends, set up a table, trade cards, and talk. Demo money only.

Live site: https://cadenprather1.github.io/slab-row/

- `index.html` – the app
- `js/net.js` – network layer (Supabase, or local test mode with `?local`)
- `js/mp.js` – accounts, saving, shows, multiplayer, real trading and voice calls
- `config.js` – Supabase project URL and publishable key
- `supabase.sql` – database tables, security rules and photo storage (run in Supabase SQL Editor)
